# TEDÜ PEK Yönergesi — çalışma taslağı v18

Programlar ve Eğitim Komisyonu üyelerinin incelemesi için hazırlanan statik sayfa.

- 18 madde ve bir geçici madde; toplam 50 fıkra.
- Her fıkranın altında açılan tam, sekiz alanlı karşılaştırma kaydı.
- Ortak iş akışı, form/rehber envanteri, sekiz açık teyit notu ve 21 kaynak.
- Türkçe arama, fıkra bağlantısını kopyalama, yazdırma ve Word indirme.

Metin baz sürümü ve kaynak kontrolü: 22 Ekim 2026. Kurumsal kabul veya hukuki teyit tamamlanmış değildir.

GitHub Pages: `main` dalının kökü. Derleme ve harici JavaScript kütüphanesi gerektirmez. `index.html`, `styles.css` ve `app.js` sayfayı oluşturur. İnceleme içeriği JavaScript kapalıyken de okunabilir.

`noindex` ve `robots.txt` arama motorlarından dizine eklememelerini ister; sayfa bağlantıya sahip kişilerce erişilebilen açık bir yayındır.
